# Python QR Code Generator

## About
Python program that generates customizable QR codes from text or URLs.

## Features
- Converts text and URLs into QR codes.
- Supports four colours: Black, Blue, Red and Green.
- Allows custom filenames and QR code sizes.
- Saves generated QR codes as PNG images.
- Includes input validation.

## Technologies Used
- Python
- PyCharm 
- qrcode library

## Installation
Install the required Python library using the following command in the terminal:

`pip install "qrcode[pil]"`

This installs the library required to generate and save QR code images.

## Execution
Run the Python file:

`python qrcode-gen.py`

Follow the instructions displayed in the terminal to generate your QR code.
